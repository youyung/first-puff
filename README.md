# 誘惑的抵擋｜菸檳教育互動課程

國一健康教育的菸檳防制課程網站。

| 檔案 | 內容 |
|---|---|
| `index.html` | 課程首頁：玩法、學生區、教師區（流程、討論題、上課用 QR Code） |
| `game.html` | 手機模擬互動遊戲（約 20–25 分鐘） |
| `worksheet.html` | 課後學習單，可列印成 A4 |
| `dashboard.html` | **教師後台**：看每位學生的完成狀況和遊戲中的選擇 |
| `config.js` | **設定檔**：後台網址、座號上限、班級選單（老師只需要改這個） |
| `apps-script.gs` | 後台程式，要貼到 Google 試算表（不會在網站上執行） |
| `.nojekyll` | 讓 GitHub Pages 直接發布檔案，不要刪除 |

---

## 一、上線到 GitHub Pages

1. 登入 GitHub，點右上角 **＋ → New repository**，取一個英文名稱（例如 `first-puff`），選 **Public**，按 **Create repository**。
2. 點 **uploading an existing file**，把資料夾裡的所有檔案拖進去，按 **Commit changes**。
3. 到 **Settings → Pages**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 等 1–2 分鐘，網址是 `https://你的帳號.github.io/first-puff/`。

---

## 二、在 GitHub 上修改檔案

### 方法 A：直接在網頁上改（改幾個字最方便）

1. 在 repository 頁面點要改的檔案，例如 `config.js`。
2. 點右上角的 **鉛筆圖示（Edit this file）**。
3. 修改內容後，點右上角綠色的 **Commit changes…**，再按一次 **Commit changes**。
4. 等約 1 分鐘，網站就會更新。學生那邊如果沒變，請他們重新整理頁面。

### 方法 B：用新檔案覆蓋（改很多地方時）

1. 在自己電腦上用記事本或 VS Code 改好檔案，**檔名要完全一樣**。
2. 在 repository 頁面點 **Add file → Upload files**，把檔案拖進去。
3. 按 **Commit changes**，同名的舊檔案會被取代。

### 班級怎麼填？

目前是學生**自己輸入班級**（例如 701），座號用下拉選單選。設定在 `config.js`：

```js
CLASSES: [],
```

- 想改成下拉選單，就把班級寫進去，例如 `["703", "706"]`。
- `MAX_SEAT: 35` 是座號最多到幾號。

### 想改遊戲內容？

在 `game.html` 裡用 Ctrl+F 搜尋：

- 劇情與對話：`async function main()`
- 知識卡內容：`const CARDS`
- 廣告貼文的陷阱文字：`const CAP`
- 搜尋結果：`const RES`

改的時候只改引號 `"…"` 裡面的文字，不要動到引號、逗號和括號。

## 三、設定教師後台（Google 試算表）

GitHub Pages 只能放網頁，不能存資料，所以用一張 **Google 試算表** 當資料庫。學生玩完後，結果會自動寫進你的試算表，`dashboard.html` 再把它整理成表格和統計。資料只存在你自己的 Google 帳號裡。

### 步驟 1：建立試算表與程式

1. 到 Google 雲端硬碟，新增一個 **Google 試算表**，取名例如「第一口之前紀錄」。
2. 在試算表上方選單點 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的內容全部刪掉，貼上 `apps-script.gs` 的全部內容。
4. 把第 7 行改成你自己的密碼（這就是教師後台的登入密碼）：
   ```js
   const TEACHER_KEY = "請改成你自己的密碼";
   ```
5. 按上方的 **儲存（磁碟片圖示）**。

### 步驟 2：部署成網頁應用程式

1. 點右上角藍色的 **部署 → 新增部署作業**。
2. 點「選取類型」旁的齒輪，選 **網頁應用程式**。
3. 設定：
   - **執行身分**：我
   - **誰可以存取**：所有人
4. 按 **部署**。第一次會要求授權：選你的帳號 → 若出現「Google 尚未驗證這個應用程式」，點 **進階 → 前往（不安全）** → **允許**。這是你自己寫的程式，所以會出現這個提示。
5. 複製 **網頁應用程式網址**（開頭是 `https://script.google.com/macros/s/`，結尾是 `/exec`）。

### 步驟 3：把網址填進 config.js

在 GitHub 上編輯 `config.js`，把網址貼在 `API_URL` 的雙引號中間：

```js
API_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
```

Commit 之後約 1 分鐘生效。

### 步驟 4：測試

1. 打開遊戲，選一個班級和座號，玩到出現結局。
2. 回到 Google 試算表，會多一個「遊戲紀錄」工作表，裡面有「開始」和「完成」兩列資料。
3. 打開 `https://你的帳號.github.io/first-puff/dashboard.html`，輸入密碼，就能看到這筆紀錄。

### 後台可以看到什麼

- 開始人數、完成人數、平均知識卡、小考平均、戶外教育那晚第一次就拒絕的比例、曾選「一口就好」的人數
- 三個關鍵選擇的分布：戶外教育那晚、補習班檳榔、看到電子煙廣告
- 每位學生一列：班級、座號、暱稱、是否完成、結局、健康、友情、知識卡、小考、各關卡的選擇、遊玩時間
- 可以依班級、完成狀態、日期篩選；點表頭可以排序；可以匯出 CSV 用 Excel 打開
- 上課時開著會每 30 秒自動更新

試算表本身也會保留所有原始紀錄，可以直接在試算表裡排序、篩選或製作圖表。

### 之後修改了 Apps Script 怎麼辦？

例如改了密碼，要重新部署才會生效：**部署 → 管理部署作業 → 鉛筆圖示 → 版本選「新版本」→ 部署**。這樣網址不會變，不用改 `config.js`。

---

## 注意事項

- **個資**：遊戲只記錄班級、座號和暱稱，不要求輸入姓名。請提醒學生暱稱不要用真名。資料存在老師自己的 Google 試算表，學期結束後可以自行刪除。
- **密碼**：後台密碼只寫在 Apps Script 裡，不會出現在 GitHub 上。請不要把密碼寫進 `config.js`，因為 GitHub 上的檔案所有人都看得到。
- **沒設定後台也能用**：`API_URL` 留空時，遊戲照常可以玩，只是不會記錄。
- 字型和 QR Code 從網路載入。學校網路若擋住 Google Fonts，會改用系統字型，不影響遊玩。
- 數據以國健署 2025 年（114 年）青少年吸菸行為調查為準。「持有電子煙」罰則目前為修法草案，遊戲只呈現現行的使用罰則。
